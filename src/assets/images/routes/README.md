Add route images in this folder using the route ID as the filename, for example `r1.jpg` or `r2.webp`.
Supported formats: JPG, JPEG, PNG, WebP, and AVIF.

Before uploading, resize each photo so its longest side is about 1400 px and save it as a JPG
(roughly 100-400 KB). Full camera photos are 5-9 MB each and make the site slow to load.
Use one file per route ID, and make sure the file extension matches the real format.
